README
===============

This directory contains supplement resources for *Computer Networks: A
Systems Approach (7E)*. The community is invited to contribute
corrections, improvements, updates, and new material under the same
terms.  If you make use of this work, the attribution should include
the following information:

|  Title: *Computer Networks: A Systems Approach*
|  Authors: Larry Peterson and Bruce Davie
|  Copyright: Larry L. Peterson and Bruce S. Davie, 2026
|  Source: https://github.com/SystemsApproach/7E
|  License: `CC BY  4.0 <https://creativecommons.org/licenses/by/4.0>`__
|

The lecture slides mirror the outline of the book, with a deck for
each chapter. They currrently incorporate the ``.png`` version of the
of the figures. You may want to substitute the editable version found
in the ``figures`` directory for each chapter (see ``.odp`` file). If
you modify these slides, or have other lecture slides you'd be willing
to share, we would be happy to host them (or include a link to them)
in this repo.
